## 一、安装与启动

1. 下载 `SmartKeyAI-2.0.0-win-x86.zip`。
2. 将压缩包完整解压到一个可写目录。不要直接在压缩包里运行，也不要只复制 `SmartKeyAI.exe`；程序需要同目录下的 Qt DLL、`platforms`、`qml` 等文件。
3. 双击 `SmartKeyAI.exe` 启动。
4. 首次启动会显示隐私说明。阅读后勾选确认框，再点“同意并继续”。未同意时，软件会阻止所有第三方网络请求。
5. 隐私确认后会自动打开设置页，请按下一节配置 AI Provider。

如果 Windows SmartScreen 提示“未知发布者”，这是因为当前开发版本没有 Authenticode 数字签名。请只在确认文件来自本仓库可信的 Release 页面后运行。主程序的 SHA-256 应为：

```text
ceed07634eab756d835571113cf5b024034e72a20b6e8b805eb24df647058ab7
```

可在解压目录打开 PowerShell 后核对：

```powershell
Get-FileHash .\SmartKeyAI.exe -Algorithm SHA256
```

## 二、配置 AI Provider

打开“设置 → AI 配置”。软件支持 DeepSeek 预设和自定义 OpenAI-compatible 接口。

### 使用 DeepSeek

1. 在“接口预设”中选择 `DeepSeek`。
2. 填写一个便于识别的配置名称。
3. 输入自己的 DeepSeek API Key。
4. 刷新模型列表并选择 Provider 当前提供的模型；也可以手动填写 Provider 文档中给出的模型名称。
5. 点“测试连接”。该操作会向 Provider 发出最小 API 调用，可能产生少量费用。
6. 测试成功后点“保存并开始对话”。

![image-20260828160234588](assets/image-20260828160234588.png)

### 使用自定义 OpenAI-compatible 接口

1. 在“接口预设”中选择“自定义 OpenAI-compatible”。
2. 填写配置名称、模型名称和 API Key。
3. 展开“高级连接设置”，确认：
   - `Base URL`：以 `https://` 开头的服务地址；
   - `Chat Path`：通常为 `/chat/completions`，以 Provider 文档为准；
   - 鉴权方式：`bearer`、`api-key` 或 `none`；
   - 使用 `api-key` 时，还需填写正确的请求头名称；
   - 超时、上下文预算和最大输出 Token 符合所用模型限制。
4. 检查界面显示的“最终 URL”，再测试连接并保存。

API Key 使用 Windows DPAPI 加密，只能由当前 Windows 用户解密。更换接口地址或鉴权方式时，为防止旧密钥被错误复用，需要重新输入 API Key。

## 三、开始对话

- 默认全局快捷键是 `Ctrl+Alt+Space`，用于显示或隐藏聊天窗口并聚焦输入框。
- 也可以单击/双击系统托盘中的“智键 AI”图标，或右键托盘图标选择“显示智键 AI”。
- 输入消息后按 `Enter` 发送，按 `Shift+Enter` 换行。
- 回答生成过程中，发送按钮会变为停止按钮；点击它可停止当前生成。
- 点“新对话”可创建新会话。
- 模型选择器可切换当前模型和思考强度。模型列表刷新目前仅对 DeepSeek 自动发现开放。
- “联网搜索”只有在当前 Provider 声明支持时才能使用；不可用时界面会给出提示。

## 四、历史记录与导出

点击主窗口左侧的历史按钮可打开会话列表。

- 点击会话可继续对话。
- 使用会话右侧操作菜单可置顶、取消置顶或删除会话。
- 删除的会话会进入“最近删除”，默认保留 7 天，可在到期前恢复或永久删除。
- 点击会话旁的导出按钮可选择目录并导出 Markdown 文件。
- 回答生成期间，部分会话切换和管理操作会暂时禁用；可先停止生成。

## 五、快捷键、后台与退出

在“设置 → 快捷键与后台”中可以：

- 点击录制区域后按下新组合键，再点“绑定”；
- 点“恢复默认”恢复 `Ctrl+Alt+Space`；
- 开启或关闭“开机后台启动”；
- 切换界面语言（跟随系统、简体中文或 English）。

如果新快捷键已被其他程序占用，绑定会失败，原快捷键仍然有效。关闭聊天窗口后程序通常仍留在系统托盘；要完全退出，请右键托盘图标并选择“退出”。

## 六、数据与隐私

- 你的聊天内容会发送给所选择的第三方 AI Provider，并受该 Provider 的服务条款和隐私政策约束。
- 聊天记录以明文 SQLite 数据库保存在当前 Windows 用户的本地应用数据目录。
- API Key 使用当前 Windows 用户的 DPAPI 加密保存。
- 诊断日志、聊天数据库和配置都保存在本机，不应复制到公开仓库或发送给不受信任的第三方。

在“设置 → 数据与隐私”中可以打开数据目录、调整是否保存聊天历史和保留期限，并分别清除日志、全部聊天或全部凭据。执行删除前请确认范围，重要会话建议先导出。

注意：“快捷键与后台”页隐私卡片里的概括性“清除本地数据…”入口，在本版本中只提交删除请求，不会自动删除聊天、日志或配置。需要实际删除时，请使用“数据与隐私”页中带有明确范围的按钮。

## 七、常见问题

### 双击后没有看到窗口

程序可能已经在后台运行。检查任务栏右侧的托盘区域及“隐藏的图标”，点击“智键 AI”图标，或按 `Ctrl+Alt+Space`。本程序只允许一个实例，再次启动会唤起已运行的实例。

### 无法发送消息

依次检查：是否已同意隐私说明、Provider 配置是否已保存、API Key 是否有效、模型名称及最终 URL 是否正确、网络是否可访问 Provider、账户是否有余额或配额。可回到“AI 配置”重新执行“测试连接”。

### 快捷键无效

该组合键可能被 Windows 或其他软件占用。到“快捷键与后台”录制另一组包含 `Ctrl`、`Alt` 或 `Shift` 的快捷键，再点“绑定”。`F12` 和单独的修饰键不能注册。

### 界面空白或图形显示异常

先更新显卡驱动。仍有问题时，可在程序目录打开 PowerShell，临时启用软件渲染后启动：

```powershell
$env:SMARTKEY_SOFTWARE_RENDERER='1'
.\SmartKeyAI.exe
```

### 如何完整卸载

1. 从托盘菜单退出程序。
2. 在“数据与隐私”中按需清除聊天、日志和凭据。
3. 若开启过开机启动，先在“快捷键与后台”中将其关闭。
4. 删除整个解压目录。

仅删除解压目录不会自动删除当前 Windows 用户下已经保存的配置、凭据和聊天数据。

# SmartKey AI reconstruction — private research archive

> 本仓库仅作为仓库所有者的私人学习、研究、测试与备份资料，不是原软件的官方仓库，也未获得原开发者或权利人的授权、赞助或背书。不要出售或用于商业用途。

仓库内容包括：

- `reverse-engineering/`：逆向分析工具、结构化证据与资源分类结果；
- `reference/`：资源恢复所需的原程序主 EXE、Stage 2 v2 对齐清单和完整 Stage 2 v3 工具/输出；
- `source/`：恢复的 QML/素材、后续修改的界面、独立编写的 C++ 代码、测试和构建脚本；
- `release/SmartKeyAI-2.0.0-win-x86/`：最终验收的 Windows 成品及随包校验信息；
- `validation/reports/`：构建、测试、隔离 smoke、打包与最终验收记录。

其中部分 QML、图片、字体、图标和其他资源来自对一个未公开源代码的 Windows 可执行程序进行分析和资源恢复，部分文件又在恢复内容基础上修改。其余 C++、测试和工具是在研究、兼容和重实现过程中编写。原软件名称、商标、代码、素材及其他第三方内容的权利归各自权利人所有。
